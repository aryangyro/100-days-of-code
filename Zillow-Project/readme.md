This project is a structured data extraction pipeline that collects real estate listing information from a Zillow-style webpage clone, cleans the data, and stores it in a structured JSON format for further analysis. The objective of the project is to demonstrate practical web scraping, data cleaning, and transformation techniques that mirror real-world data engineering workflows.
The system begins by sending an HTTP request to the target webpage using the Requests library, simulating a browser through custom headers. The raw HTML response is then parsed using BeautifulSoup, which allows precise extraction of structured elements from the page’s DOM. Instead of relying on fragile class names, the scraper targets stable data-test attributes such as property-card-price, property-card-link, and property-card-addr, following professional scraping practices that make the pipeline more resilient to frontend design changes.
Price values appear in multiple formats like “$2,895+/mo” or “$2,764+ 1 bd.” A regex-based cleaning function extracts only numeric components, removes commas, and converts values into integers. This ensures the dataset is normalized and ready for analysis or modeling. Each listing’s price, address, and link are combined into a dictionary, and all property dictionaries are stored in a list — the standard structure used in APIs and machine learning datasets.
Finally, the structured data is exported into a JSON file, enabling integration with analytics tools, databases, or web services. This project showcases key industry-relevant skills: HTTP handling, HTML parsing, data normalization, robust selector strategies, and JSON serialization. It represents a complete mini data pipeline and reflects the foundational techniques used in large-scale web data collection and processing systems.
