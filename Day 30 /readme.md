
Today I developed a Password Manager application using Python and Tkinter that allows users to securely generate, store, and retrieve passwords through an intuitive graphical interface.

The application includes a strong random password generator that combines letters, numbers, and symbols, automatically copying the generated password to the clipboard for ease of use. User credentials are stored in a JSON-based persistent data store, enabling passwords to remain available across sessions.

To make the application robust and production-safe, I implemented exception handling to gracefully manage cases such as missing or corrupted data files. The search functionality allows users to quickly retrieve saved credentials by website name, displaying results through clean popup dialogs.

This project strengthened my understanding of:
	•	GUI development with Tkinter
	•	File handling and JSON data persistence
	•	Exception handling and defensive programming
	•	Modular function design
	•	User-centric application flow

Overall, this project simulates a real-world desktop utility, moving beyond beginner scripts into application-level Python development.
