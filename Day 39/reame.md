This script is a practical example of transforming unstructured web content into an organized dataset using Python. It begins by sending a request to a travel website and parsing the HTML using BeautifulSoup. From the page structure, it extracts destination names found inside heading tags. Since scraped data often contains numbering or formatting noise, regular expressions are used to clean each city name, ensuring consistency.
The next step focuses on structure. Raw city names alone are not enough for meaningful data organization, so the script maps cities to their respective countries using a predefined dictionary. This step is crucial because it converts simple text into categorized geographic information. By pairing each city with its country, the data becomes useful for analysis, sorting, and future applications like travel planning or visualization.
Data integrity is handled carefully. The script checks for existing entries in the CSV file to avoid duplicates, ensuring the dataset remains clean even after multiple runs. A set data structure is used during sorting to automatically remove repeated city–country pairs. This makes the system resilient and efficient.
The sorting function groups cities country-wise and arranges them alphabetically. Instead of appending endlessly and creating messy files, the script rewrites the CSV in a clean, structured format with proper headers.
Overall, this code demonstrates core data engineering concepts: web scraping, text cleaning, categorization, duplicate handling, and structured storage. It shows how raw online information can be converted into organized, reusable data with a simple but powerful Python workflow.
