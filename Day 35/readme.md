
Built an interactive quiz application using Python and Tkinter that dynamically fetches questions from a public trivia API. Integrated the QuizBrain logic layer with a clean GUI to manage question flow, scoring, and answer validation. Implemented real-time user feedback with color-based UI responses (green/red) and timed transitions between questions. Designed the interface with clear separation of concerns between UI and quiz logic, ensuring maintainability and scalability. This project strengthened my understanding of event-driven programming, API consumption, and GUI state management in Python.
