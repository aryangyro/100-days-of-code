A Python automation project that tracks daily stock price movements and delivers real-time news alerts straight to your phone. 📈📲
The application monitors a selected stock using market data APIs and calculates percentage changes between recent trading days. When a significant movement is detected, it automatically fetches the latest relevant news and sends concise summaries via SMS.

The project integrates multiple external APIs, handles real-world API limitations gracefully, and formats alerts in a clean, readable way for end users. It demonstrates practical use of HTTP requests, JSON parsing, conditional logic, and third-party service integration — simulating a real notification system used in finance and trading platforms.

Built with scalability and clarity in mind, this project reflects how automated monitoring, data aggregation, and alerting systems work in production environments. ⚡📊

Tech used: Python, REST APIs, Alpha Vantage, NewsAPI, Twilio
