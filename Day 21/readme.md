Developed a fully functional classic Snake game using Python’s Turtle graphics module. The project features smooth real-time movement, keyboard-based directional controls, dynamic food generation, score tracking with an on-screen scoreboard, and accurate self-collision detection. The code is structured using a clean, class-based architecture with separate modules for the snake, food, and scoreboard, ensuring maintainability and scalability. Special attention was given to proper game-loop management, collision handling, and preventing false collisions as the snake grows, resulting in stable and responsive gameplay.
