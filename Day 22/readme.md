This project is a fully playable Pong-style game created using Python’s built-in turtle graphics library. It focuses on applying object-oriented programming principles by separating game components into clear classes such as the ball, paddles, and scoreboard.

The game includes a real-time loop, keyboard-controlled paddles, wall and paddle collision detection, score tracking, and increasing difficulty through dynamic ball speed. The project emphasizes game logic, state management, and timing control, making it a strong foundation for understanding how interactive applications work under the hood.

It is ideal for practicing Python fundamentals, OOP design, and basic game physics, and can be easily extended with features like AI paddles, sound effects, or difficulty levels.
