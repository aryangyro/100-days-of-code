This project is a simple habit tracking tool built using Python and the Pixela API. It allows users to log daily activity data by automatically creating pixel entries based on the current date. The application demonstrates practical API usage, including authentication via headers, structured JSON requests, and date handling using Python’s datetime module.

The tracker is designed with automation in mind — making it easy to extend into real-world habit tracking systems such as fitness goals, productivity streaks, or personal metrics. By integrating external APIs and handling HTTP requests cleanly, this project serves as a solid foundation for learning REST APIs, request workflows, and basic automation patterns in Python.

Perfect for beginners looking to understand API integration, daily data logging, and habit-based applications using real services.
