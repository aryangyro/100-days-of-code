# 💯 100 Days of Code – Python

> Building Python skills through daily coding & real projects.

This repository documents my journey through the **100 Days of Code (Python)** challenge.  
Instead of just watching tutorials, I build something every day to strengthen problem-solving and practical coding skills.

---

## 🎯 Purpose

I’m doing this challenge to:

- ✨ Improve problem-solving ability  
- ✨ Write Python confidently without copy-pasting  
- ✨ Stay consistent and disciplined  
- ✨ Create a public record of learning  
- ✨ Prepare for advanced, real-world projects  

---

## 📚 What Each Day Contains

Each folder includes:

- 🧩 Code written that day  
- 📝 Short explanation of the project  
- 🧠 Concepts practiced
