
This project is a browser automation bot built using Python and Selenium that plays the Cookie Clicker game automatically. The goal of the bot is to simulate human interaction by continuously clicking the main cookie and purchasing upgrades intelligently to maximize cookie production over time.
The bot first launches a Chrome browser instance and navigates to the Cookie Clicker web version. It handles the initial language selection and waits for the game interface to fully load. Once ready, the script begins its main loop, repeatedly clicking the large cookie element to generate cookies, mimicking rapid user clicks.
Every few seconds, the program checks the in-game store for available upgrades. Instead of buying items randomly, it uses a simple decision strategy: it scans through the list of products and selects the most expensive upgrade that is currently affordable. This approach improves efficiency by prioritizing higher-value items that increase production speed more significantly.
The automation runs for a fixed duration of five minutes, after which it prints the final cookie count achieved by the bot. This demonstrates the ability to combine browser automation, real-time decision-making, and dynamic web interaction.
Technically, this project highlights core Selenium concepts such as locating elements by ID and CSS selectors, handling exceptions, managing wait times, and building loops driven by time-based conditions. It also shows practical use of Python for automating web-based tasks.
Overall, this bot is a fun but educational example of using automation to interact with dynamic web applications while implementing basic strategy logic.
